# TextLab — Text Tools for Designers

**TextLab** is a modern, fast, client-side text utility application designed specifically for graphic designers, content creators, and developers. Type or paste your text once and instantly generate multiple formatted variations with zero latency.

---

## ✨ Features

- **Instant Variations**: Converts text as you type across 12 required variations:
  - `UPPERCASE`
  - `lowercase`
  - `Title Case`
  - `Sentence case`
  - `First Letter Capital`
  - `aLtErNaTiNg CaSe`
  - `PascalCase`
  - `camelCase`
  - `snake_case`
  - `kebab-case`
  - `dot.case`
  - `CONSTANT_CASE`
- **Quick Modifiers**: Single-click actions to remove extra spaces, line breaks, trim whitespace, and clean punctuation.
- **Copy All & Single Copy**: Instant visual `✓ Copied` feedback for single cards or copy all variations at once.
- **Dark & Light Mode**: Seamless dark and light themes persisted via `localStorage`.
- **Keyboard Shortcuts**:
  - `Cmd/Ctrl + K`: Focus text area
  - `Cmd/Ctrl + Enter`: Copy all variations
  - `Escape`: Clear input field
- **100% Client-Side**: No backend required, data never leaves your browser.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/adithyanpaloor/TextLab.git

# Navigate into the project folder
cd TextLab

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
```
